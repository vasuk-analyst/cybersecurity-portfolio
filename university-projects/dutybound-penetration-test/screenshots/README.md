# Screenshot evidence

This folder is reserved for sanitized, non-spoiler images captured by the project author.

Before adding an image, check it for flags, credentials, VPN profiles, cookies, session tokens, machine IP addresses, private group information, and active-machine solution details. Do not upload a walkthrough or screenshots that reveal the solution while the machine is active. Add only high-level portfolio visuals until HTB officially retires the machine and its current publication rules permit solution sharing.

Suggested non-spoiler images:

- Project overview or methodology diagram.
- Tools and lab setup with account and network details hidden.
- General SOC detection concept diagram that does not expose exploit steps.
