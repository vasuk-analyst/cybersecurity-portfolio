# Azure Honeypot and Microsoft Sentinel

This project documents an Azure Windows honeypot lab and the investigation workflow built around its authentication telemetry.

## What’s included

- `index.html` — detailed case study covering the architecture, collection path, KQL, Sentinel triage, findings, and limitations.
- `azure-vm-status.png` — sanitized evidence showing the VM was stopped and deallocated.

The report records 924 failed logon events (Event ID 4625) and two source IPs reviewed. It does not claim confirmed compromise or confirmed RDP activity.
